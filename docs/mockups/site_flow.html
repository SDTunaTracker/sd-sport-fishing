UX · Information architecture

The Tuna Tracker — site flow & navigation

How a visitor moves through the product: where they enter, the home hub that answers "what's biting and what should I book," the explore branches, the detail pages, and the conversion/retention moments. The three core journeys are highlighted first, then the full map.

Three core journeys

Every nav and link decision should make these three paths effortless.
ACheck today's bite — the daily habit
Enter (direct / search / shared link)→ Today (home)→ Latest reports · all landings→ Tap a boat→ Boat detail
BBook the best trip — the conversion
Today (home)→ "Top trip to book" / Trip Planner→ Filter by date · species · spots→ Trip detail (+ boat performance)→ Book (landing site)
CScout a boat — the research
Boats leaderboard / search→ Boat detail→ History · reviews · upcoming trips→ Follow / Book

Cross-links that keep people moving

The flow isn't linear — every data point is a doorway. Wire these so users never hit a dead end:

  • Report row → boat detail
  • Leaderboard row → boat detail
  • "Top trip to book" → trip detail → book
  • Charts "catches" pin → boat detail
  • Boat detail · upcoming trips → trip detail
  • Landing name (anywhere) → landing detail
  • Season leader → boat detail → its next open trip
  • Forecast good-day → Trip Planner filtered to that day
